# Project case studies

Architecture write-ups for client systems I built between 2018 and 2025. The code belongs to the clients, so there is nothing to run here. Each folder holds a short overview, a high-level design (HLD), a low-level design (LLD) and an architecture diagram.

For code you can run, see [ConsumerChatbot](https://github.com/sagarai2024-collab/ConsumerChatbot), [Phoenix-Watcho](https://github.com/sagarai2024-collab/Phoenix-Watcho) and [notification-api](https://github.com/sagarai2024-collab/notification-api).
