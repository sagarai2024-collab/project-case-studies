# GTPL Cable Connection – Digital Cable TV Management

> **Domain:** Digital Cable / DTH Services  

A subscriber management and online recharge portal for **GTPL Cable**. Customers can register, select plans/add‑ons, recharge online via integrated **payment gateways**, and track usage/billing. Admins can manage subscribers, plans, pricing, invoices, and analytics. The solution uses **ASP.NET MVC**, **Entity Framework + SQL Server**, **jQuery/AJAX**, and **RDLC** reports, with **TFS** for version control and CI/CD.

---

## ✨ Key Features
- **Subscriber Onboarding**: registration, KYC, address/equipment details.
- **Plan Management**: base pack & add‑ons, validity, pricing, promotions.
- **Online Recharge**: payment gateway integration; invoices & receipts.
- **Billing & Usage**: plan history, renewals, usage metrics.
- **Reporting**: RDLC‑based billing and plan analytics (export to PDF/Excel).
- **Admin Console**: CRUD for plans, subscribers, orders, promotions; dashboards.

---

## 🧱 Technology Stack
- **Framework**: ASP.NET MVC (C#), .NET Framework
- **Data**: Entity Framework, LINQ, SQL Server 2019
- **Frontend**: Razor Views, jQuery, AJAX, Bootstrap
- **Reporting**: RDLC Reports (Invoices, Collections, Plan Analytics)
- **DevOps**: TFS (version control & deployments)
